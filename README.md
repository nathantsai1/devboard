# Custom Devboard

## What is this?
This is a custom made devboard that allows users to program whatever they want. It utilizes the ESP32-WROOM-32E board, which is really cool!

## Why did I make this project?
I was curious on how a devboard used power and ground to create a relatively compact PCB. It was cool to see how all the resistors, capacitors, and transistors worked together just to filter voltage, lower/increase voltage, and stabilize power. I also learned how to take advantage of a 4-layer board and what GND does through research, which was a fun side project!

## Anything cool?
I added a sad panda and a cool snorlax to the back of the PCB! I also used USB-C instead of the standard USB-MICRO, and used smaller buttons to make them more difficult to press!

## issues?
DFM thinks the pds on both the USBC connector and USB to UART mc are too close
